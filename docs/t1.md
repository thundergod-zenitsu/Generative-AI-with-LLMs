# 3. Step 1 — Document Loading

## PDF Loader

Use
PyMuPDF

Extract **line-level structure**:

```python
{
 "text": "...",
 "font_size": 12,
 "font_name": "Helvetica-Bold",
 "x": 72,
 "y": 142,
 "page": 1
}
```

Important signals:

* font size
* bold
* indentation
* page position

Performance:

```text
100 pages < 500ms
```

---

## DOCX Loader

Use:

```python
python-docx
```

Extract:

```python
{
 "text": "...",
 "style": "Heading 1",
 "level": 1
}
```

DOCX is easy because **hierarchy is embedded**.

# 4. Step 2 — Normalize Lines

Create **clean logical lines**.

Tasks:

* merge wrapped lines
* remove page headers
* remove footers
* normalize whitespace

Example:

```text
1. Definitions
"Affiliate means any entity..."
```

---

# 5. Step 3 — Heading Candidate Detection

Goal: identify **possible section titles**.

Use **multiple signals**.

### Pattern detection

Examples:

```regex
^\d+(\.\d+)*\s+
^\([a-z]\)
^\([ivx]+\)
^[A-Z][A-Z\s]{3,}$
```

---

### Structural signals

Check:

```text
short line length
uppercase ratio
font size > body
bold font
preceded by blank line
```

---

### Candidate Output

Each line becomes:

```python
{
 "text": "...",
 "is_candidate": True,
 "features": {...}
}
```

---

# 6. Step 4 — Heading Classification

Instead of LLM, use **feature scoring**.

Example features:

```text
numbering pattern
uppercase ratio
font size delta
bold
indentation
line length
```

Score example:

```python
score = (
    pattern_score +
    font_score +
    uppercase_score +
    spacing_score
)
```

If score > threshold → heading.

Also estimate **heading level**.

Example:

```text
1 → level 1
1.1 → level 2
1.1.1 → level 3
```

---

# 7. Step 5 — Hierarchy Builder

Convert headings into **tree structure**.

Example input:

```text
1 Definitions
1.1 Affiliate
1.2 Agreement
2 Term
```

Algorithm:

```text
stack-based tree builder
```

Pseudo:

```
for each heading:
    determine level
    attach to parent in stack
```

Attach **paragraphs as content** until next heading.

---

# 8. Step 6 — Handle Broken Structure

Many contracts do this:

```text
TERMINATION

Termination for Cause
Termination for Convenience
```

Use **font hierarchy**.

Example rule:

```
largest font → section
smaller bold → subsection
```

---

# 9. Step 7 — Fallback Semantic Segmentation

If no headings detected:

Use **topic segmentation**.

Technique:

```text
TextTiling
or
embedding similarity drops
```

Segment where topic shifts.

This ensures **every document still parses**.
